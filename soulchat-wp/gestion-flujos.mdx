En esta sección podrás crear, administrar y consultar los flujos conversacionales diseñados para las diferentes campañas asociadas a la plataforma.

## Búsqueda y filtros

En la parte superior dispones de herramientas para localizar rápidamente un flujo específico:

- **Buscar:** campo de texto libre para filtrar flujos por su nombre.
- **Tipo de Flujo:** lista desplegable que permite filtrar según la categoría del flujo.

<AccordionGroup>
  <Accordion title="Flujo principal" icon="diagram-project">
    Estructura conversacional base para la atención al cliente.
  </Accordion>
  <Accordion title="Encuesta" icon="square-poll-vertical">
    Flujo destinado a la recolección de satisfacción o datos específicos post-atención.
  </Accordion>
  <Accordion title="Flujo masivo" icon="paper-plane">
    Flujos automatizados orientados a envíos de campañas masivas.
  </Accordion>
</AccordionGroup>

## Construcción del flujo

En este apartado podrás crear flujos utilizando pasos y condicionales, con el fin de brindar una variedad de respuestas automatizadas a partir de las interacciones con el cliente final.

<Tip>
  Antes de crear un flujo nuevo, revisa si ya existe uno similar usando el buscador — reutilizar y ajustar un flujo existente suele ser más rápido que empezar desde cero.
</Tip>
